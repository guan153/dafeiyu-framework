# 优缺点与适用场景

## 优点

| 优点 | 说明 |
|---|---|
| 单一情绪事实源 | 快照 + 开关，读完一处知道当前心情 |
| 可回滚 | 每个读方一个开关，改 `shadow_switches.json` 即可 |
| 可观测 | `[emotion-shadow]`、`voice_gate.json`、`emotion_snapshot.json` |
| 本地优先 | 网关/看板/家庭服务都在 127.0.0.1，不依赖云 |
| 模块清晰 | 网关、情绪内核、家庭、开关分开 |
| 聊天-only | 只开 QQ/SnowLuma/网关/AstrBot，不拉语音/生图 |
| 有安全边界文档 | SECURITY.md 明确未鉴权端点与自动发布风险 |

## 缺点

| 缺点 | 影响 | 缓解 |
|---|---|---|
| 不含插件 | 不能直接跑 QQ 机器人 | 用你自己的 AstrBot 插件 |
| Windows 绑定 | `.ps1`、盘符、编码坑 | 先按 docs/OPERATIONS 跑；跨平台自行改 |
| 无鉴权 | 8899/8765/8920 不能公网暴露 | 只绑 127.0.0.1；前置反向代理+鉴权 |
| 8920 单点 | 聊天/家庭一起哑 | 进程守护/手动看护（未内置） |
| 测试不足 | 改动风险高 | 按验收清单逐项跑 |
| 路径占位 | 首次运行会找不到文件 | 替换 `%ASTRBOT_HOME%` 等 |
| 部分能力未收口 | proactive/will/state 仍有已知问题 | 见 docs/TROUBLESHOOTING |
| License 未定 | 不能直接商用/再分发 | 等作者决定 |

## 适合谁

- 想研究"情绪闭环/单写者/网关注入"的开发者
- 已有 AstrBot 宿主，想接一套本地情绪/家庭框架的人
- 想借鉴开关、回滚、可观测设计的人

## 不适合谁

- 想 clone 后一键跑起来的人
- 想直接公网部署的人
- 需要开箱即用的多租户/生产级鉴权的人
- 需要完整插件/模型/数据的人

## 一句话

**这是一个"可读、可改、可回滚"的工程切片，不是产品。**
